# Empty Activity - XML

Empty Activity nos permite crear un proyecto con el archivo activity_main.xml

Archivos dónde mayormente se trabaja:
```
activity_main.xml
MainActivity.kl
AndroidManifest.xml
```

> [!NOTE]
> El archivo apk se encuentra en `app\build\outputs\apk\debug` de nuestro proyecto.

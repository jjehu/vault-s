# Instalación y primeros pasos 

## Node.js
*Descargar Node.js*
> https://nodejs.org/en/download

*Abrir Visual Studio Code*
> Dentro de VS crear una carpeta con el nombre preferido\
> Abrir una nueva terminal (tambien se puede desde VS con: Ctrl+ñ)

## MySQL
*Descargar MySQL*
> https://dev.mysql.com/downloads/windows/installer/

`Instalar MySQL Server y MySQL Workbench.`

*Iniciar*
> MySQL 8.0 Command Line Client\
> Ingresar la contreña previamente configurada
